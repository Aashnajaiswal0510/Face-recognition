# Models Directory

Place your trained Keras model and OpenCV Haar Cascade file here:

1. `emotion_model.h5` — Generated by running `python src/model_training.py --dataset dataset --epochs 40` on the FER2013 dataset.
2. `haarcascade_frontalface_default.xml` — Automatically resolved from `cv2.data.haarcascades` if not copied locally.
3. `training_metrics.json`, `training_history.png`, `confusion_matrix.png` — Automatically generated during model evaluation.
